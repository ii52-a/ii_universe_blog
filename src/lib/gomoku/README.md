# 星盘五子棋引擎

本地实现，规则为 15×15 自由五子棋，黑先、无禁手，长连获胜。无需外部服务、模型或账号。

## 搜索

- 每个方向以 9 格三进制棋形表识别成五、活四、冲四、活三与跳形；组合四四、四三与三三用于排序。
- 落子后只更新受影响的四条线上 ±4 格棋形，并维护距离 2 格内的候选点。
- 双 32 位 Zobrist 哈希，262,144 项置换表，保存上下界与最佳着法。
- 迭代加深至最多 14 层；PVS / Alpha-Beta 搜索，优先已知好手。超时返回最后完整迭代，所有模拟落子通过 finally 恢复。
- 叶节点额外延伸强制防四和冲四，最多 8 层；主搜索前用最多 18 手连续冲四（VCF）寻找可证明的迫胜。
- 搜索候选点为根节点最多 24、内部 12–16。这是浏览器时间预算下的启发式搜索，不是全局完备求解。`proven` 只标记立即成五或已验证的 VCF。
- 太阳系、古德尔带、银河系的预算由 `rules.ts` 中的 `searchBudget` 维护。阶段由本地对手已落子次数决定，悔棋随局面回退。后两档需非游客登录。会话未就绪前不启动搜索，匿名恢复高档存档会降为太阳系。实际深度由局面和设备决定，迫胜与唯一挡五点会提前返回。内部 quick / deep / maximum 标识保留，兼容已保存对局。

威胁搜索的算法背景：[Allis 等，Go-Moku Solved by New Search Techniques](https://cdn.aaai.org/Symposia/Fall/1993/FS-93-02/FS93-02-001.pdf)。本目录为独立实现，未复制论文中程序或第三方引擎源码。

## 线程与对局

每次计算运行在独立 Web Worker。悔棋、重开、切换模式、修改预算和离开页面均终止旧计算；请求代数检查阻止旧结果回写。引擎失败可重试或改为同屏双人。

本机自动续局使用 `ii-starboard-gomoku-v1`，恢复时校验步数、棋子交替、重复落点与终局。人机悔棋退回到人类上次落子前，执白时保留电脑的开局第一手。

## 验证

`node scripts/gomoku-engine-check.mjs`：立即胜负、断点防守、边角与斜线、三三交叉、五手连续冲四证明、超时回退、规则和悔棋边界。

`node scripts/gomoku-ui-check.mjs`：真实 Worker 对弈、取消与重试、双人终局、保存恢复、响应式与无障碍。需要本地前端和 Microsoft Edge。
