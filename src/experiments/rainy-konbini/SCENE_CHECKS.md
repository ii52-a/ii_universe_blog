# 幻想边界场景检查与测试模式

## 使用

打开 `/fantasy-boundary`，右下角的 `test 丧尸模式` 默认关闭。原小雨 NPC 与跟随按钮已移除，其关节模型改为灰绿色皮肤、破旧衣着、红眼与前伸手臂的丧尸。

- 开启 test 直接进入第一人称丧尸模式，同时启用跳跃、攻击、生命和耐力，天空变为暗猩红并出现红月。
- WASD / 方向键移动，Shift 奔跑，空格跳跃。按住空格不会连续起跳，空中不能二段跳。
- 鼠标左键单发射击，间隔 0.45 秒；按住不连发。可见子弹速度为每秒 14 个场景单位，有枪声及短暂枪口闪光。
- E 看向附近座位坐下或起身。坐下恢复耐力更快，但仍可能受攻击。坐下时空格先起身。
- 触屏左侧拖动移动、右侧拖动转头；右下角提供射击、跳跃、按住奔跑、坐下/起身按钮。
- M 释放或重新捕获鼠标，Esc 暂停并返回模型视角；「继续测试」恢复原位置。页面隐藏时战斗冻结。
- 开启 test 时切换为 136 BPM 的战斗配乐，使用鼓点、低音和不协和音。B 切换配乐开关，退出 test 恢复雨夜配乐。
- 倒下后不能移动或攻击，可「重新开始」。关闭 test 清除丧尸、子弹和寻路任务，并恢复原天空。
- 空中关闭 test 仍正常下落；回到普通步行地面前保留支撑与下落处理。

## 生存与感知

生命与耐力均为 100。实际奔跑每秒消耗 10 耐力，停跑后等待 1 秒，以每秒 6 恢复。坐下立即以每秒 28 恢复。耗尽后需要恢复至 20 才允许继续奔跑。

每批至多生成 6 个实体，初始等待 3 秒，此后每 12 秒尝试生成。默认同时存活上限为 24。候选点数量有限，避开墙体、未加载区域、其他实体并优先避开正前方。

丧尸在 8.75 个场景单位内有视线时发现玩家，墙壁会阻挡视线。枪声在 22 单位内记录开枪地点，引发调查，不会持续读取躲起来的玩家位置。关闭枪声音效仅静音，仍会产生游戏中的噪声。失去视线保留 5 秒记忆，声音调查保留 8 秒，之后重新游荡。

近战距离 0.95，脚下高度差需小于 0.65，并检查墙体遮挡。攻击有 0.34 秒前摇、1.1 秒间隔，每次造成 12 点伤害；玩家受击后有 0.65 秒短暂保护，避免群体同帧叠伤。跳跃可躲过出手时的地面攻击。丧尸生命 50，子弹伤害 25；子弹检测整个飞行线段，优先撞上最近的墙或实体，避免高速穿过薄墙。

丧尸在原有提速基础上再提高 10% 移速。游荡为每秒 0.726 单位，追击为每秒约 2.05 至 2.36 单位。命中会触发短暂闪红、后仰和火花。

## 群体寻路

`NavigationWorld.ts` 使用玩家道路、坡面、楼层、楼梯和碰撞快照。规划按不超过 0.08 的间隔检测，额外保留 0.045 的边缘余量。实际步行复用玩家的物理子步和墙面滑动。浅落差按单向走下规划，避免把能走下的路缘判成断路。自动门在规划中可通行，实际移动仍检查门的位置。

`CrowdNavigation.ts` 从目标反向生成距离场，落到同一路点的实体共用结果。常规步长为 0.4，受阻时尝试 0.2 的半格连接。网格包含高度，靠近家具的目标可在同一高度附近寻找落脚点，隔墙目标分开计算。静态邻接边缓存复用。每次最多接收 48 个实体、维护 4 个活跃目标场，每个场最多展开 9,000 个节点。超过目标场数量的调查目标等待后续选择，近距离可直接通行的目标仍能追踪。

`crowd.worker.ts` 在后台 Worker 中分片计算，共享每片 180 节点、约 4 毫秒的预算，间隔 12 毫秒让出执行。目标请求间隔约 0.32 秒，追击目标轻微移动时会保留规划锚点，最近的目标场可复用。结果约每 100 毫秒发布。主线程验证路线能从当前位置接入，允许近期仍可用的结果衔接等待中的追击。Worker 不可用时使用主线程限额后备，每帧最多 48 节点、约 2 毫秒。

碰撞检查确认能走通的短路段会合并，楼层和跳跃连接会继续参与路径校验。近处实体通过空间分桶寻找邻居，每个实体最多处理 8 个邻居。宽处预测碰撞并尝试侧向速度，门口和楼梯按前方实体速度跟进。受阻时保留走廊，转身根据实际位移平滑更新。

玩家腾空时，丧尸会追查当前水平位置下方的支撑面。顶面不可达时，可以改追附近同层落脚点。楼梯按实际通行方向生成路径，山顶住宅楼梯脚保留转弯空间。

丧尸与玩家使用相同的起跳速度和重力。跳上矮平台、跨越同层低障碍或跳下高墙前，会检查起跳面、完整轨迹和落脚面。最大下跳落差为 3.8，超过 1.2 的落差可选择更远的安全落点。相邻落点由丧尸轮流使用。模型与子弹复用对象池，重新开始、关闭模式和离开页面均清理寻路任务。

附近高处目标优先尝试合法跳跃，跳跃无法通过时检查攀墙。`WallClimb.ts` 检查可走到的墙脚、连续墙体、全程身体空间和可站立的顶面。目标在水平 4 个单位内、落差不超过 4.3 时可以触发。攀爬速度为每秒 1.45，翻越护栏后落地继续追击。同一墙面通道或相邻落点会预约排队，头顶遮挡、悬空楼板和无墙体的位置不能攀爬。每帧最多为一只丧尸检查新攀爬方案，并错开重试时间。

远距离跨越上下街区时，沿朝雾坂的分段通行点双向规划。二层停车平台按高度识别为已在上层，不再误导回坡底。普通路线受阻超过 1.1 秒时，先检查侧向退让点，保留之后仍可走的路线。

每移动约 0.42 个单位产生一次短暂脚步声，普通步行听觉范围 4.5，奔跑范围 6。记录声音发生处，持续约 0.55 秒，不更新静止玩家的位置。楼内转角丢失视线后可沿最近脚步声位置搜索。枪声仍有更大的 22 单位调查范围。

攻击前摇为 0.28 秒，冷却为 0.65 秒，连续攻击周期约 0.93 秒。头发包含 13 束不规则尖簇与垂发，使用实例化网格合并为一次绘制，保持现有头部动画和受击闪光。

## 本轮修复

| 问题 | 处理 |
| --- | --- |
| 碰撞注册以世界高度 0.65 为下限，低矮长椅等实体会被漏掉 | 纳入低矮实体，保留贴地装饰和原有明确可穿过标记 |
| 多层楼板原来和装饰一样跳过碰撞，加入跳跃后会穿透 | 三层住宅、山顶住宅、别墅楼板单独注册，提供脚下支撑与头顶阻挡 |
| 原高度查询只识别脚边 0.28 范围内的楼层，起跳后可能失去二楼 | 新增独立的全楼层支撑查询，选取脚下最近的有效楼面 |
| 阅览室坡道只有单面平面，从低处观察会消失 | 用封闭楔形实体替换，保留与高度查询一致的坡面 |
| 北侧长椅右侧起身点距离高低路面交界不足角色半径 | 将起身点移回河岸平台，按实际地面计算高度 |
| 便利店门前地垫缺少支撑，纳入低矮实体后可能挡住入口 | 补齐平台和踏步，普通步行也识别可跨上的低台阶，地垫纹理不单独阻挡 |
| 便利店室内高度范围越过门前平台，延伸至两侧人行道 | 收窄高处支撑范围，让两侧人行道恢复其实际高度 |
| 旧路灯穿过阅览室屋顶，另一盏位于坡道车行区域 | 移至室外与路肩，灯杆底部按各自地面高度放置 |
| 步行时原来的相机近裁剪面容易越过近距离墙面 | 步行近裁剪距离由 0.12 降至 0.035，模型视角保留原值 |

阅览室补充荐书板、书本与书签，门外增加雨伞架和暖色门灯。装饰避开门洞、坡道和座位起身点，不增加新的实时光源。

## 实现边界

`WalkingPhysics.ts` 负责跳跃、重力、墙面滑动、平台支撑和碰头；`WalkingController.ts` 负责输入、场景碰撞登记、座位和模式切换；`Terrain.ts` 提供道路、坡面、楼层及楼梯的高度。

每个物理子步最多 1/120 秒，单帧累计最多 0.1 秒，避免切回后台时大幅穿越场景。起跳速度为 4.6，重力为 13，平地起跳约 0.8 个场景单位，连续台阶允许高度为 0.28。

实体保留原有空间网格与包围盒碰撞。曲面、斜屋顶使用保守包围盒，并非逐三角形物理模拟。河道水面、铁路禁入区及地图边界仍不可进入，测试模式不解除这些限制。楼梯的视觉踏步继续使用平滑坡面行走高度，楼板独立参与垂直碰撞，避免普通步行在平台边缘卡住。

## 回归检查

先启动 Vite 开发服务，再运行 `npm run test:fantasy`。默认地址为 `http://127.0.0.1:4173`，可用 `BASE_URL` 修改。测试使用本机 Microsoft Edge，测试插桩只由 Playwright 注入，不发布到网站。

- 20 / 60 / 144 FPS 起跳高度、稳定落地、薄墙阻挡、低天花板、跳上平台及离开平台下落。
- 山顶住宅、三层住宅、别墅楼梯，阅览室坡道、河桥、完整朝雾坂道路，两种模式分别通行。
- 六栋坡上房屋的 24 个地基角、紫色房门前通路、四个摊位前通路、全部座位的起身点。
- 阅览室坡道底面、真实楼板碰头、二楼落地、防止二段跳、空中关闭模式。
- 离开页面后的场景清理。

`npm run test:zombie` 单独检查丧尸测试模式：

- 耐力消耗、耗尽恢复阈值、坐下恢复、受击保护与死亡重开。
- 6 / 12 / 24 / 48 个实体共享目标场，实景长椅绕障、不可达目标和全局预算。
- 三栋住宅的双向楼梯、低平台跳跃、单向下跳、低天花板阻挡和大横墙轮流下跳。
- 自动门通行、枪声调查地点、墙后目标、跳跃躲避近战。
- 玩家实际移动进便利店，以及从街道进入山顶住宅后转向上楼，丧尸通过正常视线感知持续跟进。
- 单发冷却、实际鼠标按住不连发、子弹命中、枪声音频启用、暂停继续、触屏按钮及窄屏无横向溢出。
- 关闭模式后实体、子弹、Worker 和天空恢复，离开页面无浏览器脚本错误。

压力测试输出实际计算时间，不能等同于所有设备的整帧帧率；测试环境使用 Edge 软件 WebGL，渲染与图形硬件上的表现不同。

### 本次执行结果（2026-11-07）

住宅检查覆盖三栋住宅的双向路线，以及三层住宅第二段楼梯，共八条路线。额外的 `node scripts/zombie-traversal-check.mjs` 检查三只丧尸轮流攀墙、完整斜坡双向通行、低屋顶跳跃、较高屋顶攀爬和落地攻击，还检查低天花板与悬空楼板拒绝攀爬。

可设置 `SKIP_RENDER=1` 单独验证实际场景物理和寻路，跳过软件 WebGL 的重复渲染。该模式输出的截图不用于外观验收。压力测试中的移动更新时间不包含整帧渲染成本。

`npm run build` 检查类型并生成生产构建。场景不引入新的依赖。
