# 首页与版式参考

这部分记录制作前联网找到、并实际参考过的开源主页与官方站点。没有复制其中代码或素材，只抽取了信息组织方式。

## 已下载源码

- [Ladvace/astro-bento-portfolio](https://github.com/Ladvace/astro-bento-portfolio)（MIT）
  - 已克隆到 `.references/astro-bento-portfolio`
  - 参考点：bento 卡片密度、博客与留言簿并置、RSS、浅色主题下的纸张感
  - 本项目改为 React + Vite，并重新设计了 12 栏首页、玩具组件和文章/账号体系

## 联网查阅

- [leungcheukfai/ericleung.hk](https://github.com/leungcheukfai/ericleung.hk)：OpenBio 风格的 bento 个人主页，参考侧栏信息分层
- [coolCoderD/Ochi](https://github.com/coolCoderD/Ochi)：award-winning 风格主页，参考不对称构图与大字排版
- [Airy Personal Page · Astro](https://astro.build/themes/details/airy-personal-page/)：留白与轻量个人站
- [Studio.K — High-End Editorial Landing](https://contra.com/p/2RclYmAN-studiok-high-end-editorial-landing)：编辑式大标题与纸片层叠
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)：交互与可访问性审查
- [Awwwards](https://www.awwwards.com/) / [Godly](https://godly.website/)：用于观察 2025–2026 年个人站与作品集趋势

## 取用边界

- 只借鉴布局节奏、卡片密度、字体层级与交互模式
- 没使用任何参考站的图片、插画、Logo 或源代码
- 所有插画均为本项目内联 SVG；文案为虚构的「迟迟 / 半日」内容
